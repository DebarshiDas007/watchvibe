# WatchVibe redesign options (demo only, not deployed)

Open any file in this folder with a browser while `python -m http.server 8099` runs here (they share `data.js`, real titles and TMDB images from the catalogue).

| Option | Feel | Fonts (all free for commercial use) | Palette |
|---|---|---|---|
| 1 Noir Cinema | Editorial, letterboxed, serif, film grain | Gambetta + Satoshi (Fontshare) | black, ivory, brass |
| 2 Neon Arcade | Synthwave, glowing, ticker, stickers | Clash Display (Fontshare) + JetBrains Mono (Google, OFL) | indigo, magenta, cyan, yellow |
| 3 Paper Pop | Light, neo-brutalist, hard shadows, bento | Cabinet Grotesk (Fontshare) + Space Mono (Google, OFL) | cream, orange, lime, sky, pink |
| 4 Glass Aurora | Frosted glass, soft aurora light, serif italics | General Sans (Fontshare) + Instrument Serif (Google, OFL) | midnight, teal, blue |
| 5 Swiss Index | Strict grid, mono labels, charts as lists | Switzer (Fontshare) + IBM Plex Mono (Google, OFL) | paper white, black, electric blue |

Resources used: only free ones from the shared list (Fontshare, Google Fonts / open-source fonts, Coolors-style palettes). Effects (grain, marquee, glass, aurora, numbered Top 10) are written from scratch in plain CSS. Paid or unclear-licence items (MotionSites, Layers, SceneAI, React Bits Pro, Bencho paid packs, the Figma backgrounds library) were not used.

`shots/` holds the screenshots (desktop 1440 and phone 390). `phones.html` shows all five at 390 px.
